# 0008. 分离无显示 Server 与工作台发布构建

- 状态：superseded by ADR-0010
- 日期：2026-11-16

## 背景

远程主机可能只有无显示的服务器环境。完整工作台所需的 GPUI、Tree-sitter 和桌面系统库会增加这类主机的安装与运行负担，但分别实现主机服务又会造成会话和项目管理行为分叉。

## 决策

同一代码库提供两种发布构建：

- **Metis Server** 包含主机服务、客户端协议、项目与 Git 操作，以及 Harness 运行所需组件，面向无显示环境，不引入图形界面、编辑器或 Tree-sitter。
- **Metis 工作台** 包含完整的 Metis Server 能力，并提供图形界面、代码编辑和差异审查。

两种构建共享同一份主机服务实现和客户端协议。工作台复用主机服务，不维护另一套本地会话逻辑。

## 影响

无显示主机不需要安装桌面图形依赖，工作台仍可通过一次启动使用完整功能。构建与发布检查需要同时覆盖两种产物，并验证 Server 构建可以在没有图形会话的环境运行。
