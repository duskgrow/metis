# Metis 产品范围与里程碑

Metis 让个人用户在一个工作台中操作多台主机上的智能体，并跨设备接续工作。编辑器用于完成代码修改和差异审查，整体运行方式见 [Metis 架构](architecture.md)。

## 首个可用版本

首个版本先打通本地工作流程，一次打开一个 Git 项目并运行一个活动会话：

1. 在 Linux 上启动 Metis，自动准备运行环境。
2. 添加并打开一个项目。
3. 创建智能体会话，发送提示词并处理审批。
4. 查看和修改代码，审查智能体的改动。
5. 关闭 Metis，结束本地智能体工作。

## 里程碑

### 里程碑 0：验证关键集成

技术选型依据见 [MVP 技术选型调研](research/mvp-technology-selection.md)。以下清单全部完成后，再搭建完整 MVP 流程。

**Harness 与运行时**

- [x] 由 Metis 启动固定版本的扩展 Harness（dsh），跑通会话创建、提示词、流式输出、停止当前任务和审批；相同请求标识重试不会重复提交提示词。
- [x] 通过 Cordis 插件和 profile 为 dsh 添加项目文件、Git 和主机／项目／会话映射，并从 Rust 工作台完成调用。

- [x] 强制终止工作台后，本地扩展 dsh 与智能体均停止，再次启动创建新的运行时。
- [x] 制作携带 Node.js、Harness、Metis 扩展和依赖的无显示最小运行包，确认其不包含 GUI 与 Tree-sitter 依赖。
- [x] 在预装系统 Git 的干净 Ubuntu 24.04 无显示环境完成运行包安装、启动和真实项目的 Git 调用。
- [x] 在预装系统 Git 的干净 NixOS 无显示环境完成运行包安装、启动和真实项目的 Git 调用。

**GPUI Kit 界面**

- [x] 在 Ubuntu 24.04 与 NixOS 的隔离 Wayland 会话中，使用 Mesa lavapipe Vulkan 和外部 Fcitx5，验证组合输入、候选提交、中文显示和系统剪贴板复制粘贴。
- [x] 连续追加流式 Markdown，确认文本与代码块正确更新；位于底部时自动跟随，向上滚动后保持阅读位置。

- [x] 快照与增量事件通过连续会话序号衔接；在断开期间和重连交接时产生事件，验证消息、任务状态和审批事件按序应用，不丢失、不重复。
- [x] 验证主机接口认证与项目路径边界，拒绝未授权调用及项目范围外的文件和 Git 操作。

### 里程碑 1：本地可用

- 一次启动即可使用完整工作台。
- 添加、打开项目，编辑文件并审查差异。
- 创建、接入和取消智能体会话，查看流式输出并完成审批。
- 本地扩展 dsh 随工作台自动启动；工作台正常关闭或异常退出时，该运行时及本地智能体均停止，重新打开时创建新的运行时。

### 里程碑 2：多主机与跨设备

- 通过系统安全外壳协议连接远程主机，提供扩展 dsh 无显示运行包的远程安装、启动和升级。
- 从一台设备管理多台主机上的项目与智能体。
- 从另一台设备接入原主机，继续会话、查看任务和处理审批。

### 里程碑 3：连接与偏好同步

- 增加设备注册、主机发现、连接票据和中继。
- 同步用户偏好，处理版本冲突并保留备份。
- 在设备之间提供一致的连接体验。

### 里程碑 4：发布准备

- 打包 Linux 和 macOS 的无显示运行包与工作台，以及所需资源、许可证和第三方声明。
- 验证真实数据的升级、备份、崩溃恢复和干净机器安装，检查日志中的敏感信息。
