# 0007. MVP 客户端与主机服务使用 JSON-RPC

- 状态：superseded by ADR-0010
- 日期：2026-11-16

## 背景

图形界面与主机服务分属两个进程，既需要项目、会话和审批命令，也需要持续的会话事件。两端都使用 Rust，类型共享和订阅支持比分别组装 HTTP 命令与 SSE 客户端更直接。

## 决策

MVP 客户端通过 WebSocket 上的 JSON-RPC 调用主机服务，使用 `jsonrpsee` 实现方法调用与事件订阅。普通操作使用 RPC 方法，智能体输出和状态变化使用订阅。

该协议只用于 Metis 客户端与主机服务之间。主机服务仍通过独立适配器接入固定版本的 DeepSeek Harness。

## 影响

命令与事件共用一条连接，客户端和服务端可以共享接口类型。连接恢复仍由会话协议负责：重连后通过会话快照和连续序号衔接增量事件，不能依赖 JSON-RPC 订阅本身补齐业务状态。
