# 0009. 区分私有与常驻 Server 生命周期

- 状态：superseded by ADR-0010
- 日期：2026-11-17

## 背景

本地工作台应自动准备运行环境，并在关闭界面时结束本地工作；用于持续运行或跨设备接入的主机则需要在客户端断开后继续工作。Server 的生命周期需要符合用户对本地工作台和常驻主机的理解，同时复用同一套服务实现与客户端协议。

## 决策

本地工作台启动仅供所属界面使用的私有 Server。私有 Server 随工作台正常退出或崩溃而关闭，并停止其管理的本地智能体与 Harness；再次打开工作台会创建新的私有 Server。

用于持续运行或跨设备接入的主机使用常驻 Server，其生命周期独立于客户端。两种模式共享主机服务实现和客户端协议，工作台通过相同的客户端接口使用它们。
